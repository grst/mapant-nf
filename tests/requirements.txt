# Python dependencies for the tests, and for running bin/*.py outside a container.
#
# Pinned so that CI fails when someone changes this file, not on a random Tuesday when a dependency
# releases. It overlaps containers/tiler/Containerfile without being generated from it: that one is
# what the tasks run with, this one is what the tests and a local `nextflow run` need.
#
# jsonschema and shapely are test-only: the first checks assets/schema_tiles.json, the second is the
# independent geometry check on the halo that bin/plan_grids.py itself no longer needs.
#
# numpy, pillow and rasterio are here for bin/make_vector_tiles.py, which traces karttapullautin's
# classified rasters. shapely 2.1 or newer, because that is where the coverage simplifier arrived:
# without it the tracing still works, but every traced boundary keeps a vertex per pixel corner.
#
# pyshp for bin/osm_shapes.py. Chosen over geopandas, which the image used to carry, because the
# matcher mirrors karttapullautin's rules down to reading only DBF text columns -- raw field types
# are the thing being modelled, and pyshp hands them over without a dataframe or a GDAL in between.
#
#   python -m venv .venv && .venv/bin/pip install -r tests/requirements.txt
